# forja-web

Arquivos de atualização do app **Forja** (treino e dieta), criado por Elenilton Siqueira.

O app instalado no celular consulta `version.json` e, quando há versão nova, baixa o pacote em `updates/`.
Aqui não há dados pessoais de uso: só o código das telas e as imagens dos exercícios (Free Exercise DB, domínio público).
